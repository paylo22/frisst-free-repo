# frisst-free-repo

Мой первый учебный репозиторий на GitHub.

Здесь я учусь основам Git и GitHub:

- **репозиторий** — папка с проектом и историей изменений;
- **коммит** — сохранённое изменение с описанием;
- **push** — отправка изменений на GitHub.

Это изменение было сделано с помощью Claude — можно открыть вкладку **Commits** и посмотреть, как оно выглядит в истории.
